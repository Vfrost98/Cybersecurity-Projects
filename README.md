# Cybersecurity Projects

This repository holds my personal scripts, lab work, and security research. I use this space to track the tools I build and the environments I test out. 

If you are just browsing, here are the projects I'm currently most proud of:

### Repository Structure
I keep my work separated by domain. You can find documentation and instructions inside each folder:

* **[CTF-Writeups](./CTF-Writeups)**: Step-by-step walkthroughs and methodologies from HackTheBox, TryHackMe, and other security competitions.
* **[Offensive-Security](./Offensive-Security)**: Exploit scripts, custom scanners, and payload generators.
* **[Defensive-Security](./Defensive-Security)**: Incident response playbooks, detection rules, and monitoring tools.
* **[Malware-Analysis](./Malware-Analysis)**: Reverse engineering notes, YARA rules, and sandbox configs.
* **[Digital-Forensics](./Digital-Forensics)**: Scripts for memory analysis and timeline reconstruction.
* **[Application-Security](./Application-Security)**: Code auditing tools and secure coding examples.
* **[Network-Security](./Network-Security)**: Packet analysis scripts and IDS/IPS rule sets.
* **[Cloud-Security](./Cloud-Security)**: Auditing scripts for AWS/Azure environments.
* **[Cryptography](./Cryptography)**: Cryptanalysis tools, hashing scripts, and post-quantum research.
